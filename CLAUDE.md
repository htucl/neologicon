# CLAUDE.md

## Working style

Added 22 November 2026 at the author's request; the same text is held in the author's claude.ai personal preferences, which apply to every project.

Before starting any non-trivial task, list what you would need to know that I have not told you. If a gap would change the approach, ask before editing any file, using numbered yes/no questions. If there are no gaps, say "No gaps" and proceed.

For any plan, state your confidence (0 to 100%) that it will work and what specifically would raise it to 100%. Treat this as a list of gaps, not a calibrated probability.

### End of every substantial response

End with a section titled "80/20", placed last, with a horizontal rule above it. Bottom line only, nothing new. Include a line only when it has real content:
Result: always. One line.
Next: only if I must act. Numbered, action in bold.
Decide: only if the choice is mine. Numbered yes/no questions.
Watch out: only a real risk.
Git: only if a repo changed. What changed, and whether it is committed or pushed.
Bold the key actions so the bold text alone gives the answer.
